# Public evaluation data license

The synthetic knowledge base, retrieval questions, expected document identifiers, and
example prediction files under `evaluation/` are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The intent regression set is an original, sanitized test fixture created for this
project. It does not contain production conversations or client records and is also
released under CC0 1.0.

No production database, customer document, support conversation, source PDF, access
token, or private model output is included.

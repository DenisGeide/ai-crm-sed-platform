# Public screenshots

These images document the public showcase with demo or sanitized data.

The retained set intentionally excludes:

- customer records and production conversations;
- signed download URLs, JWTs, API keys, passwords, and session identifiers;
- private hostnames, local filesystem paths, and deployment configuration;
- source documents belonging to customers.

The screenshots are product evidence, not a runnable copy of the private
commercial backend. Use the repository's [RAG Quality Lab](../evaluation/README.md)
for the fully reusable public implementation.
